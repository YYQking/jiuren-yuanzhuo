# 社会热点雷达实施计划

**目标：** 把已确认的热点浏览方案落实为可直接运行的独立桌面包。

**结构：** `brainstorm/hotspots.py` 负责来源、解析、筛选、配额、缓存；`brainstorm/hotspot_page.py` 负责后台刷新、卡片、状态和导航；`brainstorm/qt_app.py` 集成大厅入口。保留已有讨论流程和历史格式。

本目录没有 Git 仓库；在当前已授权工作目录连续执行并保留既有发布目录。
