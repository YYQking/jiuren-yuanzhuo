# 让圆桌像一群人在讨论，而不是一份模板填 N 遍

日期：2026-10-27
状态：已实施并跑真实模型验证

## 问题

用户反馈：「我发现这些人的说话还是像模板套模板，不像一群人在讨论问题」。

这不是模型内容坏，而是**形状完全一致**。拿真实跑测 20 条发言量化（`artifacts/analyze_transcript.py`）：

| 指标 | 改前（real-event-3） |
| --- | --- |
| 字数 | min 154 / 中位 222 / max 257，20 条全部在 150–257 |
| 开场 | 8 个开场里 6 个是「我先说…」 |
| 收尾 | 9 条以「最后…」收尾 |
| 每条的骨架 | 接话 → 表态 → 「但是」→ 条件 → 反问，五拍齐全 |

九个人各自把同一副五拍骨架填一遍，读起来就是"模板套模板"。

## 为什么会长成这样

1. **提示词要求每条都写满**：业务模式「200–350 字」，事件模式「120–250 字」。真实对话里大部分是 30–70 字的一句半，长度一致本身就是最大的破绽。
2. **可信度规则要求每条摆三样**：事件模式原文是「三种可信度必须让人一眼看出来」，模型于是每条都写「我知道…听说…我猜…」，形成新的三段式。
3. **席位只有职责、没有口吻**：九个 Role 的 prompt 都是"关注什么、要找什么"，模型只能写成同一个分析师的声音。
4. **没有点名义务**：模型可以对着空气发表观点，`replies_to` 填了也不会写进正文。

## 做法

### 1. 席位有自己的口吻（`Role.voice`）

`brainstorm/models.py` 给 `Role` 加 `voice: str = ""`；`brainstorm/roles.py` 为 9 个商业席位与 8 个八卦席位各写一条**说话习惯**（不是职责）：

- 创业实践者：先算钱和时间，爱打断问成本，句子短促
- 真实需求者：只讲自己或身边人的遭遇，句子碎
- 怀疑者：一开口挑一个具体假设来打，口头禅「凭啥」
- 乾明：命令句、少解释、被顶撞抬声调
- 艮石：半天不说话，一开口两三个短句

提示词里以「你说话的习惯：…」注入，与「职责：…」「提示：…」并列。

### 2. 篇幅由程序按条分配

`TurnPlan.length_hint`（`short` / `normal` / `long` / `host`），`assign_length()` 在 `_guard()` 里统一赋值，所以**模型编排出来的发言也受同一套规则约束**：

- 主持人 → `host`（120–200 字）
- 总结 / 阶段总结 → `long`（180–240）
- 席位第一次开口 → `normal`（80–140）
- 其余 → 按 `LENGTH_CYCLE = ("short","short","normal","short","normal","short")` 循环，多数是 30–70 字

### 3. 反模板约束

`brainstorm/voice.py` 的 `ANTI_TEMPLATE_RULES` 注入到两种模式的提示词里：

- 不许每条都写成同一副骨架，一条只做一件事（接一句 / 顶一句 / 补一个事实 / 问一句 / 认个错 / 换个角度）
- 禁套话开场（我先说、我先开个头、实话实说、说白了、作为一个…）
- 禁分点（第一/第二/第三、首先/其次/最后），禁"总的来说/综上所述"
- 禁复述主题、禁把别人刚说的话重复一遍再表态
- 有回应对象时第一句就点名，不许对空气说话
- 不许沿用上一位的开场句式

### 4. 一次风格重写

`looks_templated()` 只看开头 16 个字（半句之后说「说白了」是人话，不算）。命中且不是主持人 → 带着具体批评重发一次：

```
你上一次的发言开头是套话「我先说」。请重写这一条：删掉开头的套话，
第一句直接说内容，篇幅按上面的要求，只做一件事。
```

第二次解析失败就**保留第一次的答案**——不为风格丢掉整条发言。

## 验证

真实模型两场事件讨论 + 一场商业讨论（`artifacts/real-voice-1` / `real-voice-2` / `real-voice-biz-1`）：

| 指标 | 改前 | 改后（事件） | 改后（商业） |
| --- | --- | --- | --- |
| 字数 | 154–257 | 53–162 | 59–156 |
| 「最后」 | 9/20 | 1/20 | 2/21 |
| 点名 | 65% | 95% | 71% |
| 开场重复 | 6/8 同一句 | 各不相同 | 各不相同 |

单元测试 266 → 283（`tests/test_voice.py` 15 项：长度分档、套话识别、首句窗口、按条分配、17 个席位都有独立口吻）。

## 不做什么

- 不做"随机长度"——确定性循环，测试与跑测才可复现。
- 不改业务模式里被测试依赖的规则文字（intent / stance_change / 不得重复）。
- 不让重写无限重试：一条最多一次风格重写、一次 JSON 修复。
