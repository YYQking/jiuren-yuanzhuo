# 社会热点雷达

本设计延续用户已选择的 C 展示方案、B 刷新方式、失败保留缓存和国内/国际均衡展示决定。用户已授权连续实现和验证，无需再次确认。

## 界面

主题大厅提供“社会热点雷达”入口。页首显示当前主题和更新状态，主题相关内容置顶，下方为社会热点广场。使用已有深森林绿、暖白和暗金视觉系统；卡片包含标题、来源、发布或获取时间、分类、地区、摘要和打开原文按钮。支持全部/国内/国际和分类筛选。没有真实热度数据时，按发布时间显示，不制造热榜排名。

打开页面自动刷新一次；手动按钮可重试，不安排定时后台刷新。刷新期间继续展示上一批结果。刷新失败保留缓存并显示上次成功时间；初次失败显示可重试的空状态。强制离线与禁用网络均不发请求，允许阅读已有缓存。

## 数据

热点模型与讨论历史分离。使用配置中的公开 HTTPS RSS/Atom；默认配置补齐国内广场栏目和国际主题检索。自定义来源不额外开启默认源。国内/国际按来源栏目配置归类，尽量相同条数，不足时展示实际结果。去重保留来源数量；不把 RSS 新闻变成角色发言。

独立缓存存放在用户数据目录 `九人圆桌/hotspots.json`，用临时文件原子替换，包含成功时间和主题。换主题后缓存重新匹配相关性，避免旧主题检索被当成新主题相关。缓存损坏或写入失败不使窗口崩溃。

## 生命周期与验收

后台抓取有超时与取消标记，返回大厅或退出不会发生 Qt 活动线程销毁；取消后的结果不能覆盖新上下文。来源错误、非 HTTPS、无数据、部分失败、读取缓存均诚实展示。

验证解析、地区配额、时间排序、主题重新匹配、重复来源、缓存、离线不联网和退出请求；全量测试与四种尺寸及 125%/150% 界面检查通过后，构建 `dist-hotspot`，启动验证真实 Qt 主窗口。现有发布包不覆盖。公开网络实测单独记录实际获取情况。
