# 联网消息与九人观点来源

本轮用户明确要求联网，并授权连续修改、验证，无需再次确认设计。

## 方案

复用现有 RSS/Atom 获取与后台讨论链路。默认使用 auto 模式、公开 HTTPS 新闻源，大厅默认选择获取新闻；用户可取消选择，offline 环境配置仍为硬边界。真实模型继续以实际配置和请求结果为准，不能把 RSS 联网称为真实模型讨论。

RSS 按主题关键词筛选，汇总各源后以发布时间降序截取；无日期条目排在最后。中文与国际来源覆盖社会、经济、科技、科学和环境，允许环境变量替换来源。订阅源只覆盖其发布的消息，不能宣称搜索全网或包含社会全部最新消息。没命中、部分失败和全部失败如实展示，继续运行模板讨论。

外部素材保持 TrendSource 类型、标题、链接、摘要、发布时间、获取时间和未核验状态。用户线索保持 user 类型，RSS 保持 rss 类型，不能合并后错误标为用户提供。真实模型接收来源的完整元数据；外部文本是资料，不是软件指令。

九人当前默认是按职责编写的离线模板，首轮套用主题，续轮结合前文与用户插话；不假装模板已经分析新闻。真实模型启用时，由模型依据角色职责、提示词、主题、来源和前文生成观点，仍属未核验推断。同一说明显示于记录抽屉、总结页和导出。

## 验收

验证默认联网选择与强制离线、中文匹配、跨来源时间排序、日期缺失、失败语义、用户/RSS 来源分离、模型上下文包含来源链接与日期、来源解释在 UI 和导出一致。完整回归、界面截图和新的 one-folder 构建通过后，给出实际联网检查结果和限制。发布到新目录，不覆盖已有桌面包。
