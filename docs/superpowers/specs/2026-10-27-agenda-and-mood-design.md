# 分层议题 + 情绪账本：让讨论能长、脸色从话里长出来

日期：2026-10-27
对应需求：「20轮对话太短了」「没必要整个正反面翻面」「触及到某个人利益了就……」「翻脸太程序化」

## 1. 问题

三件事叠在一起：

1. **长度**：一场固定约 20 条，聊到一半就到点，问题刚展开就被总结。
2. **翻面太程序化**：原来按「这个人上次说话隔了几条」机械换面，读起来像收到指令。
3. **商业桌也带阴阳**：商业痛点桌的人各有立场，不需要"好的一面/坏的一面"这套。

## 2. 做法

### 2.1 分层议题（`brainstorm/agenda.py`）

- 商业痛点五层：现象 → 原因 → 谁受益谁付代价 → 现有做法为什么不够 → 可下手的切口与前提。
- 事件讨论八层：到底发生了什么 → 谁受损、谁得利 → 各方说法和背后的动机 → 怎么处理的、代价值不值 →
  这事该怎么收场 → 同类事以前怎么处理的 → 谁该先动、怎么动 → 还差什么才能下结论。
- `LAYER_TURNS = 6`：每层至少 6 条，这一层没聊透不换层。
- 八层走完回到第 1 层，但带着「这些已经说过了」的清单，禁止原地重复。
- 主持人「整场收束」只在第 4 层之后才可用（`may_conclude`），避免第 2 层就总结。

### 2.2 情绪账本（`brainstorm/mood.py`）

- 说话的人可以给**别人**记一笔：`reactions: [{"seat": "kun", "delta": -1, "why": "被当面挑错"}]`。
- `validate_notes`：一条最多两笔、不能记自己、不能记主持人、正负号必须对（伤人的只能负、捧人的只能正）。
- 账本 `mood_of(history, seat)`：累加 → 每 `FADE_EVERY=4` 条衰减 1 点 → 夹在 −2..2。
- 脸色 `face_for_mood`：`>0` 阳面、`<0` 阴面、`0` 看先前；两次变脸之间至少隔 `CHANGE_COOLDOWN=3` 条。
- 提示词里给的是**账本**（"坤兰现在脸色：心里不爽，因为你说她这行没用"），不是"你该翻面了"。
- 模型没写 reactions 时，反驳/追问会自动记一笔给被回应的人（`_ensure_reaction`）——反驳总得有个对象。

### 2.3 商业桌不带阴阳

`resolve_face` 只在 `mode == "event"` 时算脸色；商业桌的牌上没有三颗点，转录里也不写脸色。

### 2.4 桌面看得见

`RoundtableCanvas` 每个座位下方画三颗点（红=挂脸、暗金=正常、金=心情好），
被晾着的座位下面写「一直没人接他」（`quiet_seats`：最近 5 条既没说话、也没人提他）。

### 2.5 质检只卡重复与编造

`parse_review` 里 `avoided`（没答全）单独出现不算不合格；只有 `repeats` / `fabricated` 才触发重写。
`fabricated` 收窄为"把具体数字、文件名、机构原话当真说，或冒充亲自查过"——「我听说」「我猜」不算。

## 3. 实测（真实模型，事件桌，额外 8 条）

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 发言条数 | 20 | 22（不再是硬上限） |
| 情绪记录 | 0 | 8 笔 |
| 阴面发言 | 0（全阳面） | 3 |
| 质检重写 | 5/8 | 1/8 |
| 请求数 | 45 | 39 |
| 总用时 | 79.3s | 67.1s |

## 4. 不做

- 不做"按情绪强度决定发言长度"这类二次加工：脸色只影响口气，不影响轮次安排。
- 不让账本直接写进提示词当命令（"你现在必须翻脸"）——那又变回程序化。
