# 九人圆桌 · 头脑风暴

一个中文的 Windows 桌面工具：你给一个题目，桌上一群人围着它吵，吵完给你一份结论。

不是"问 AI 一个问题"，是**看一群人怎么把一个题目掰开**——有人抬杠、有人要数据、有人打圆场，最后主持人收一句。

---

## 三个分区

大厅里点标题下面的三个按钮就能换桌，整桌人一起换掉，不用重开程序。

| 分区 | 桌上几个人 | 它在聊什么 | 最后给你 |
| --- | --- | --- | --- |
| **商业痛点** | 九人：趋势分析师、行业从业者、创业实践者、技术与实现顾问、真实需求者、普通路人、用户研究员、跨界创意者、怀疑者 | 这事儿值不值得做、谁疼、能不能成 | **机会档案**：机会方向、目标用户、支持理由、主要风险、待验证假设、下一步 |
| **事件讨论** | 八人：乾明、坤兰、震山、巽竹、坎川、离霞、艮石、兑溪 | 这事儿到底怎么回事、谁受损谁得利、怎么收场 | **吃瓜纪要**：这事儿算什么、牵扯到谁、有实锤的部分、吵得最凶的点、还只是传言、接下来看什么 |
| **观点讨论** | 八人：主张者、挑刺者、数据员、行内人、条件派、动机派、类比手、外行 | 这句话站不站得住、能信到什么程度 | **说法体检单**：这说法在说什么、谁在这么说、站得住的理由、反例与边界、还缺什么证据、怎么用 |

### 每个分区的一点脾气

- **商业痛点**：九个职业视角，每个人有自己的立场，没有"正反方"这套东西。
- **事件讨论**：八个人各有阴阳两面——热情的人也会刻薄，稳重的人也会急。**不是按轮次翻脸**，是被惹到了才变脸（有人当面挑他的错、损害到他的利益、被晾着没人接话）。
- **观点讨论**：一条硬规矩——**不许编数**。要证据就说清缺什么：多少、哪一年、谁统计、样本是谁；没有就说没有。

## 怎么用

1. 打开 [Releases 页面](https://github.com/YYQking/-/releases/latest)，下载 `jiuren-yuanzhuo-2026-10-27.zip`（就是九人圆桌的完整包，GitHub 只让用英文字母做附件名）。
2. 解压到任意文件夹（**不要**只把里面的 exe 拖出来——exe 只有 2.4MB，缺了 `_internal` 跑不起来，必须整个文件夹一起用）。
3. 双击 `九人圆桌.exe`。
4. 大厅里：选分区 → 点牌选人（最少两张）→ 填题目 → 开桌。
5. 讨论时**点一下走一条**，不会自动播；随时可以插话，也可以结束并总结。

详细说明见包里的 `使用说明.txt`，或者仓库里的 [docs/使用说明-详细版.md](docs/使用说明-详细版.md)。

### 要用真模型，得填自己的 Key

不填也能用——那是**离线模拟**，桌上有谁、说什么都由本地模板生成，界面上会明确写着「离线模拟」。

想用真模型：大厅点「AI 设置」，填接口地址、模型名、API Key，勾选启用后保存。支持任何 OpenAI 兼容接口（DeepSeek、硅基流动、通义、OpenAI 都行）。

- 地址填到 `/v1` 为止，别自己再加 `/chat/completions`。
- Key 用 Windows 的 DPAPI 加密存在你自己电脑上（`%LOCALAPPDATA%\九人圆桌\`），**不随软件包发给别人**；别人拿到包也得填自己的。
- 花的钱是你自己账号的钱，这个软件不代收。

## 从源码跑

需要 Python 3.10+ 和 PySide6：

```text
python -m pip install PySide6
python app.py
```

跑测试：

```text
python -m unittest discover -s tests
```

打包成 exe（用 Qt 的 spec，不要用旧的 Tkinter spec）：

```text
pyinstaller --noconfirm --clean --distpath dist-qt --workpath build-qt 九人圆桌-Qt.spec
```

一键构建 + 刷新桌面版和分享包 + 校验哈希：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File tools/deploy.ps1
```

## 说实话的边界

- 桌上那九位/八位是**同一个模型扮演的不同视角**，不是九个真 AI，也不是九个真人。
- 模型**没有实时新闻**。事件讨论里的事实来自你贴的素材；它自己"回忆"的旧闻会标成模型自述、未核验。
- 讨论里的一切观点都标着「未核验」——它能帮你想清楚，不能替你做事实核查。
- 离线模拟只是让你没有 Key 时也能看界面和流程，别把模拟内容当真。
