# 网页原型（赌桌版）

这是「讨论过程」这一页的新交互原型。**只做手感，不联网、不调模型**，里面的 20 条发言是提前生成好的死数据（来自一场真实跑测），所以打开就能一条条点着看。

## 怎么打开

双击 `index.html` 就行（用 Chrome / Edge 打开）。

## 这一版的样子

绿绒赌桌、木包金边的桌沿、中央一个底池（每说一条就丢一枚筹码进去，阴面的筹码偏蓝），八个人围着桌子坐，桌沿上沿坐着荷官（主持人，不占席位）。

每个人面前：一张铜牌、一小摞筹码、一张**暗牌**。暗牌平时牌背朝上，这个人一翻面，牌就翻过来亮出「阴」。

## 怎么点

| 操作 | 效果 |
| --- | --- |
| 点一下屏幕 / 空格 / → | 往前一条 |
| ← / ↑ | 回看一条 |
| 鼠标停在头像上 | 看这个人的卦名、阳面、阴面各是什么 |

## 这版想让你判断的三件事

1. **像不像赌桌**：绿绒、金边、筹码、暗牌、荷官，差什么？
2. **翻面够不够狠**：牌翻过来、头像变冷色、整屋色温跟着变——能不能一眼看出"这人翻脸了"。
3. **说话感**：正文一句一句浮现、谁在回谁有线、我确定／我听说／我猜分色——读着累不累。

## 自己验的工具

- `python tools/check_web_preview.py`：静态校验（席位、发言条数、头像、DOM 引用有没有断）
- `python tools/shot_web.py web-preview/index.html 输出.png --clicks 6`：用 QtWebEngine 截图
- `python tools/analyze_shot.py 输出.png`：数像素，确认绿绒和金边真的画出来了（防止"白屏但文件很大"的自欺）
