# 网页原型（S1 · 剧场夜）

这是「讨论过程」这一页的新交互原型。**只做手感，不联网、不调模型**，里面的 20 条发言是提前生成好的死数据（来自一场真实跑测），所以打开就能一条条点着看。

## 怎么打开

双击 `index.html` 就行（用 Chrome / Edge 打开，别用很老的 IE）。

## 怎么点

| 操作 | 效果 |
| --- | --- |
| 点一下屏幕 / 空格 / → | 往前一条 |
| ← / ↑ | 回看一条 |
| 鼠标停在头像上 | 看这个人的卦名、阳面、阴面是什么 |

## 这版想让你判断的三件事

1. **聚焦**：一次只有一个人在亮，其余人压暗——你觉得"正在听谁说话"这件事清楚了没有。
2. **翻面**：同一个人从暖金环变冷青环、整屋色温跟着变，你能不能一眼看出"这个人翻脸了"。
3. **说话感**：正文是一句一句浮现的，不是整段贴上去；"我知道／我听说／我猜"三种说法有颜色区分。
